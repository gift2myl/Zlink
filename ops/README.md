# 灵之数字员工远程运维 Demo · 官网部署

本版本替换 zlink.help 官网首页，使用现有 gift2myl/Zlink → Vercel lock 发布链路。

- 根目录 index.html 是新首页；应用模块、图片、数据、Three.js 均位于 ops/。
- 沿用原静态站部署，无构建步骤，无新增后端；脚本依赖随站部署，公共地图与地形瓦片按可见视口从对应数据提供方请求。
- 旧版保留于备份分支 backup/zlink-before-ops-20261119；旧版提交 a2a736b1a77282da338a7aec4327217add4a19ac。
- 本地需从仓库根目录提供 HTTP 服务，例如 python3 -m http.server 8080；不能只服务 ops/。

设备报表来自用户运维截图，采样日期未知，实际可见7个型号、8条设备记录，不代表全局设备在线率。

4位数字员工展示监控、诊断、工单调度与经验蒸馏；4条事件可执行诊断→工单草稿→模拟复验，状态保存在当前浏览器localStorage。没有真实设备控制、实际派单、账号鉴权或共享后台数据库。CSV导入只更新本地台账，不能覆盖已核验公开样本ID，也不自动地图布点或生成三维。

## 北京房源采集接入

采集目标为自如公开地图北京（110000）“更多→灵之智能→确定”的可租房源。当前地图 URL 不保存筛选状态，不能仅凭 URL 或 HTTP 200 判断筛选完成。

本地已安装 Scrapling 0.5.1 解析组件。原生 Fetcher 所需额外浏览器相关依赖安装被自动审批拒绝，因此本版本通过普通 HTTP 传输配合 Scrapling 解析；不使用 StealthyFetcher、挑战破解、代理轮换或自动浏览器。

- `ops/assets/crawl-status.json` 保存本次安装能力、目标范围、抓取时间、有效页数、记录数与终止原因。
- `ops/assets/crawled-properties.json` 保存核验过筛选证据的采集结果。安全校验响应不计为成功列表页；空结果或失败不会替换原 `properties.json` 的历史样本。
- `ops/tools/` 提供可复用采集脚本及依赖说明。脚本只在普通访问可用、筛选和分页有来源证据时收录数据；当前自如地图的 JavaScript 安全校验阻断了全量采集，未取得全量明细。
- 房源台账按 24 条分页，保留公开快照、采集批次和浏览器本地 CSV 的来源区别。公开记录优先，房源 ID 统一为字符串；搜索和区域筛选会重置分页。
- 新收录房源不会自动获得三维模型、真实遥测或房屋精确坐标。现有三维样板仍只对应 810151211。

本网站为静态演示。采集脚本在受控执行环境中运行并产出数据文件，网站展示最近一次提交的结果；没有在访客浏览器中持续抓取，也没有创建定时采集任务。


## 北京公共地图版本 1.2

- **地图**：OpenStreetMap Standard 正常视口瓦片；三维引擎 MapLibre GL JS 6.19.0，以同一 WebGL2 context 承载 Three.js 房源标记；浏览器不支持时明确显示 Leaflet 1.9.4 二维兼容模式。
- **地形**：Mapzen / AWS Terrain Tiles，Terrarium 编码、256 像素瓦片、地形夸张 1.2 倍。仅表示地表高程；不据此生成未经验证的楼栋与室内结构。
- **当前位置数据**：原有 10 条公开历史样本经一次性地址核对，7 条为 OSM 小区对象参考点，3 条为最近地铁站参考点，精确房间坐标 0 条。原 properties.json 没有被写入推断坐标。
- **商圈**：1 条“太阳宫”来自先前实际读取的自如详情；其余 9 条为原列表最近地铁站周边候选，等待验证。OSM 街道、suburb 与自如商圈是不同字段，不互相冒充。
- **界面**：区域、商圈/候选片区、演示待办筛选；地图点位与逐套清单联动；点开查看定位精度、来源、商圈依据、房源资料与演示事件。原 500+ 标签只保留为原地图快照。
- **运行范围**：此次没有重新请求自如受阻页面，没有取得北京全量房源。真实设备状态未接入；橙色标记仅表示未完成的演示待办。
- **数据文件**：`assets/property-geography.json` 保存逐条匹配证据；`assets/map-sources.json` 保存引擎、地形、坐标系和署名配置；`tools/geography-cache/` 保存查询缓存与人工选取依据；`tools/geocode_properties.py` 为限制在现有样本的离线补全工具。
- **请求控制**：仅在地图可见时初始化公共地图；无瓦片预取、离线打包、POI 网格扫描或访客端地理编码。遵守 OSM 署名与缓存规则。公共服务无 SLA，生产规模应使用有服务承诺的供应商或自托管。

来源与具体约定见 `tools/MAP-DATA.md`。WebGL2 地图与地形路径已按当前 API 审查；本次云浏览器没有 GPU，只可验证真实 OSM 二维兼容地图和交互，不能据此声明三维 GPU 视觉已验证。
