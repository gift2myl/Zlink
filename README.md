# Z-LINK 业主换锁网站

首页直接展示三款外门智能锁，顺序为：

1. 自如灵之 ZH-B0110 指纹锁：主推。
2. 鹿客 V5Air：次推。
3. 鹿客 S6MAX：自住与更多开门方式的选择。

选择产品即可查看说明，并复制可编辑的咨询内容。没有在线下单、预约或支付后台。维保、机械锁作为后续常见问题保留；不含内部培训材料。

## 产品素材与信息边界

- ZH-B0110 采用用户本轮指定的 800×800 产品图，原图直接使用，未裁切或重绘；没有以旧款门锁图代替。
- V5Air 和 S6MAX 采用原项目已确认型号的图片。
- ZH-B0110 的指纹锁定位来自业主方提供的信息；App、网关、联网和账号管理条件未核实，不自行推断。
- V5Air 的供货版本、开门方式、App 与联网条件需服务人员确认。
- S6MAX 的三面指脉、结构光 3D 人脸、天地双摄、4.7 英寸内屏来自已提供的产品资料。日常开门无需自如 App 或额外网关；远程视频对讲与开门需鹿客管家 App 和网络。
- 新换装全系列随附一把机械钥匙。未发布未经核实的价格、质保年限或上门时效。
